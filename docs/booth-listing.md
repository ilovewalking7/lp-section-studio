## なぜ BOOTH か

| 販売先 | 手数料の目安 | 判断 |

| **BOOTH** | **5.6% + 22円** | **採用。**日本語・DL販売がネイティブ・手数料が最も安い |

| note | 実質15%前後 | 販売には使わない（集客記事のみ） |

手数料は変わるので、出品直前に BOOTH の公式ページで再確認すること。

集客は note、決済とダウンロードは BOOTH、という分担にする。note の記事末尾から BOOTH へ送る。

## 商品説明（そのまま貼る）

```
UIコンポーネント880個。買い切りです。月額はありません。

■ React が要らない現場でも使えます

880個のうち397個は、React も Babel も含まない静的HTMLとして書き出せます。
Tailwind を1行読み込むだけで表示されるので、PHP・Rails・Hugo・WordPress に
そのまま貼れます。

※ 残り483個は状態や操作を持つため、静的版は見た目のみです（操作は動きません）。
　 397個という数字は実際に全件書き出して数えたものです。

■ 全880個が4つの機械検査を通っています

・axe-core による構造アクセシビリティ検査
・デザイントークンのコントラスト計算（WCAG の相対輝度）
・キーボードで操作できるかの検査
・実ブラウザ・幅375px での横スクロール検査

CIで毎回全件に対して走ります。この検査を導入したとき、自分のコンポーネントから
109件の違反が見つかりました。すべて修正済みで、現在は4つとも0件です。

・アイコンだけのボタン29箇所に読み上げ用の名前が無かった
・ダークモードの主ボタンの文字が 4.32:1（AA基準は4.5:1）だった
・入力欄の枠が背景と 1.27:1（1.4.11 の基準は3:1）でほぼ見えなかった
・26個のコンポーネントがスマホ幅でページを横に破っていた

目視では気づけない種類のものです。

■ 収録内容

・コンポーネント 880個（React / TypeScript / Tailwind、1ファイル完結）
・静的HTML 880件（うち397件は React 不要でそのまま動く）
・MCPサーバ 全部入り版（Claude Code / Cursor から直接取り出せる）
・shadcn 互換レジストリ（npx shadcn add で他プロジェクトへ取り込み）
・スタジオ（検索・ライブプレビュー・コピー画面）

■ 13のスタイルテーマ

和風／洋風／ミニマル／ブルータリスト／グラスモーフィズム／レトロ・Y2K／
ラグジュアリー／北欧／メンフィス／ニューモーフィズム／ボタニカル／
プレイフル／ダークテック

react / lucide-react / clsx + tailwind-merge と、同梱のUIプリミティブのみ。
外部画像URLは使っていないので、ファイルを1つ置けば動きます。

■ まず無料で試せます

MCPサーバの無料版に100個入っています（すべてReact不要のもの）。
28カテゴリに散らしてあるので、品揃えは無料枠だけで分かります。
```

## 配布物の構成

```
lp-section-studio-v1.0.0.zip
├─ README.md              使い方・導入手順
├─ LICENSE                ライセンス条文
├─ components/            React/TypeScript ソース 880件
├─ html/                  静的HTML 880件 + index.json（standalone 判定つき）
├─ registry/              shadcn 互換 JSON 885件
├─ mcp/                   MCPサーバ（全部入り版）
└─ studio/                ビルド済みスタジオ（ローカルで開ける）
```

生成手順:

```bash
npm run html                              # 静的HTML 880件
node scripts/build-mcp-bundle.mjs --all   # MCP全部入り版
npm run registry                          # shadcn配信JSON
npm run build                             # スタジオ
```

## 公開の順番

1. **MCP を npm に公開**（無料版100個）— 入口を先に作る
2. **note 記事を公開** — 集客。記事末尾から MCP と BOOTH へ
3. **BOOTH に出品** — 決済とダウンロード

MCP が先なのは、記事にもBOOTHにも「まず無料で試せます」と書けるようにするため。
逆順だと、読んだ人がその場で試せない。
